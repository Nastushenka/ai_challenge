# Правила работы с репозиторием

## Номер задания в коммитах

- Каждый новый commit message должен начинаться с номера задания в формате: `[Задание N] Описание изменения`.
- Текущее задание: **Задание 1**.
- Все коммиты, созданные до добавления этого правила, также относятся к **Заданию 1**.
- Номер задания меняется только после явного сообщения пользователя о переходе к следующему заданию.
